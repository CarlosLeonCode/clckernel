# CLC Kernel Web Design Rule — Anti-Card Fatigue & Organic Flow

## 🚫 Principle: Avoid "Card Soup" & Grid Box Fatigue

When designing or modifying landing pages and UI components for CLC Kernel:

### 1. Hard Limits on Cards
- **No Nested Cards**: NEVER place bordered/boxed cards inside an already bordered container card (e.g. no "boxes inside boxes").
- **Limit Repetitive Grids**: Do NOT default to repeating 4-8 identical bordered rectangular cards.

### 2. Approved Alternative Layout Patterns
- **Open Editorial Typography**: Clean multi-column text with strong typographic hierarchy and subtle spacing rather than hard box borders.
- **Connected Streams & Timelines**: Visual connected paths (e.g. Circular Wheels, connected flow diagrams, linear pipelines with directional connectors `────►`).
- **Minimal Row / Data Streams**: Borderless horizontal rows with soft hover backgrounds and clean badge pills instead of separate cards.
- **Interactive Single-Focus Panels**: Interactive segmented tabs or dials that update a single clean inspector panel (e.g., File Tree Inspector, Governance Wheel Spotlight) rather than rendering 6+ duplicate heavy cards.
- **Floating Pill Badges & Tickers**: Borderless inline tool badges for ecosystems and integrations.

### 3. Visual Standard
- **100% White / Light Theme**: Dominant `bg-white` and `bg-slate-50`, crisp slate text (`text-slate-900`, `text-slate-600`), and subtle borders (`border-slate-200` or `border-slate-100`).
- Use accent colors (Cyan, Emerald, Indigo, Amber, Rose) intentionally on active nodes, badges, and status dots.
