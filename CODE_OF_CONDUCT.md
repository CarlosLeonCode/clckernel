# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The full text at that link applies; this page summarizes it and explains how to
report a problem in this project.

## Our pledge

We want participation in CLC Kernel to be welcoming and free of harassment for everyone, whatever their
background, identity, experience level or opinions. Contributors are expected to be respectful, to give and
accept constructive feedback gracefully, to take responsibility for their mistakes, and to focus on what is
best for the community.

Unacceptable behavior includes harassment, insults or derogatory comments, sexualized language or imagery,
personal or political attacks, publishing someone else's private information without permission, and any
other conduct that would reasonably be considered inappropriate in a professional setting.

## Scope

This code of conduct applies in all project spaces — the GitHub repository (issues, pull requests,
discussions, reviews) and any other channel run for the project — and when someone represents the project in
public spaces.

## Reporting

Report incidents privately to the maintainer, [@CarlosLeonCode](https://github.com/CarlosLeonCode), through
a private report at <https://github.com/CarlosLeonCode/clc_forge/security/advisories/new>. Title it
"Code of Conduct report" so it is not mistaken for a vulnerability.

Please do not report conduct issues in a public issue. Reports are handled as confidentially as possible, and
the maintainer will not retaliate against anyone who reports in good faith.

## Enforcement

The maintainer reviews every report and decides on the response, following the Contributor Covenant's
enforcement guidelines. Depending on severity, consequences range from a private correction, to a formal
warning, to a temporary ban, to a permanent ban from project spaces.
